# نرم‌افزار جامع PM تجهیزات — نسخه ۴٫۰

این پروژه نسخه دسکتاپ ویندوزی نرم‌افزار PM است. تعداد تجهیزات محدود به ۲۰ یا ۴ دستگاه نیست؛ هر تعداد تجهیز را می‌توان از داخل برنامه اضافه کرد. تعداد ثبت‌شده در صفحه تجهیزات نمایش داده می‌شود.

## امکانات موجود در رابط برنامه
- داشبورد مدیریتی: تعداد تجهیزات، دستورکارهای باز، سررسیدهای معوق و نزدیک، نرخ انجام PM و کمبود قطعات
- بانک تجهیزات: افزودن، ویرایش، جست‌وجو، دسته‌بندی، محل استقرار، سطح اهمیت، وضعیت، مدل و سریال؛ کد تجهیز تکراری پذیرفته نمی‌شود
- برنامه‌های PM: تعریف فعالیت، تناوب روزانه تا سالانه یا دوره سفارشی، مسئول، آخرین انجام، چک‌لیست و دستورالعمل
- دستورکارها: صدور دستی یا خودکار از سررسیدها، اولویت، مسئول، وضعیت، چک‌لیست، هزینه، توقف و قطعات مصرفی
- انبار قطعات: تعریف قطعه، موجودی، حد سفارش، قیمت، گردش ورود و مصرف و هشدار کمبود
- تقویم و هشدار: فهرست سررسیدهای آینده و معوق و اعلان‌های برنامه
- گزارش‌گیری و چاپ، خروجی Excel و بازیابی اطلاعات چندشیتی
- کاربران محلی با نقش مدیر، تکنسین و بیننده
- پشتیبان‌گیری و بازیابی JSON و Excel
- رابط فارسی و راست‌چین؛ تاریخ‌های نمایشی با تقویم شمسی
- اجرای آفلاین؛ کتابخانه Excel داخل بسته برنامه است و برای کارکردهای اصلی نیاز به اینترنت ندارد

## ساخت فایل اجرایی ویندوز با GitHub Actions

1. فایل ZIP را Extract کنید.
2. تمام محتویات پوشه `PMEquipment_Universal_v4` را در ریشه مخزن خصوصی GitHub خود بارگذاری کنید؛ پوشه `.github` نیز باید همراه فایل‌ها باشد.
3. در GitHub وارد زبانه Actions شوید و گردش‌کار `Build PM Equipment Windows EXE` را اجرا کنید.
4. پس از پایان موفق، وارد اجرای سبزرنگ شوید و از بخش Artifacts فایل `PMEquipment-Windows-x64` را دریافت کنید.
5. ZIP خروجی را در ویندوز Extract کنید و `PMEquipment.exe` را اجرا کنید.

## نکات مهم
- در این محیط امکان اجرای Visual Studio / Windows و ساخت و آزمون واقعی EXE وجود نداشت؛ این بسته، سورس و گردش‌کار آماده ساخت است، نه فایل EXE ساخته‌شده و تأییدشده.
- داده‌های این نسخه در فضای محلی WebView ذخیره می‌شوند. از بخش تنظیمات، مرتباً پشتیبان JSON یا Excel تهیه کنید. حذف داده‌های برنامه یا پاک‌کردن داده‌های WebView می‌تواند اطلاعات محلی را حذف کند.
- نقش‌های کاربران در این نسخه برای تفکیک دسترسی داخل همان نصب محلی هستند؛ این نسخه سامانه چندکاربره شبکه‌ای با دیتابیس مرکزی نیست.
- ارسال پیامک مستقیم به سرویس‌دهنده و نیازمند API Key معتبر و اتصال اینترنت است؛ قابلیت پیامک را پیش از بهره‌برداری عملی با حساب سرویس‌دهنده خود آزمایش کنید.
- پیش از استفاده عملیاتی، ثبت/ویرایش تجهیز، تعریف PM، تکمیل دستورکار، مصرف قطعه، خروجی Excel و بازیابی پشتیبان را روی رایانه ویندوزی آزمایش کنید.
